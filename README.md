# Student Record Management System

## About the Project
This project is a Student Record Management System developed using the C programming language.

## Features
1. Add Student
2. Display Students
3. Search Student
4. Update Student Details
5. Delete Student
6. Calculate Class Average
7. Find Class Topper
8. Student Performance Alert

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- String Handling
